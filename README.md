
# Mini Bowling Alley

#### A fully functional miniature bowling alley

## What

Contains a bowling alley with a full miniature ball and pin set. Can actually be used. Also contains a self-returning ramp for balls and pins. The alley has slots for placement that guide the pin spots. Also contains a ramp to roll the ball down for fun/assitance

## How to use

Download the STL file or go to this link to get a file of your choice:

[Onshape Model](https://cad.onshape.com/documents/d685b01fa95033bdfd52ae3e/w/8ca3d03a748c35268e92843d/e/47f61168d7d890c68016e040?renderMode=0&uiState=6af333e2eaa7f2a62de60855)

Then use a slicer like Bambu Studio to slice. Enable supports, and all other default settings will work. Then print and enjoy!!! Then put the pins in their spots, and roll the ball!!!!

## Design

Made entirely in Onshape using common tools. Done in ~1 hr.
