What: contains a bowling alley with a full minature ball and pin set. Can actually be used. Also contains a self-returning ramp for balls and pins.

HOw to use: download the stl file or go to this link to get a file of your choice: https://cad.onshape.com/documents/d685b01fa95033bdfd52ae3e/w/8ca3d03a748c35268e92843d/e/47f61168d7d890c68016e040?renderMode=0&uiState=6af333e2eaa7f2a62de60855
Then use a slicer like Bambu Studio to slice. Make sure to enable supports, but all other default settings will work. Then print and enjoy!!!
Then put the pins in their spots, and roll the ball!!!!
Made entirely in Onshape using common tools. Done in ~1 hr.
